# Data

This project uses the UCI Machine Learning Repository dataset **Predict Students' Dropout and Academic Success**
(4,424 students, 36 features plus a 3-class target).

- `raw/` holds the original download.
- `processed/` is reserved for derived datasets.

**Citation:** Realinho, V., Machado, J., Baptista, L., Martins, M.V. (2022). *Predicting Student Dropout and Academic Success.* Data, 7(11), 146.

The notebook downloads the data automatically in Step 2, so the raw file does not need to be committed.
